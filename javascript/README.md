# JavaScript examples

Requires Node.js 18 or later (for native `fetch`). No dependencies to install.

```bash
export USCLIMATEDATA_API_KEY=your-key-here
node javascript/stations.js
node javascript/climate-monthly.js
node javascript/station-capabilities.js
node javascript/normals-monthly.js
node javascript/normals-monthly-extended.js   # requires Growth tier
node javascript/normals-daily.js              # requires Developer tier
node javascript/normals-daily-extended.js     # requires Growth tier
```
