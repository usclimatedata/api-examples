# TypeScript examples

Requires Node.js 18 or later.

```bash
cd typescript
npm install
export USCLIMATEDATA_API_KEY=your-key-here
npm run build
node dist/stations.js

# Or run an example directly with a TypeScript runner:
npx tsx stations.ts
```

Files:
`stations.ts`,
`climate-monthly.ts`,
`station-capabilities.ts`,
`normals-monthly.ts`,
`normals-monthly-extended.ts` (Advanced Access),
`normals-daily.ts` (Developer tier),
`normals-daily-extended.ts` (Advanced Access).
